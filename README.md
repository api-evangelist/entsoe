# ENTSO-E

European Network of Transmission System Operators for Electricity (ENTSO-E) provides the Transparency Platform REST API, a synchronous RESTful interface for accessing pan-European electricity market data. The API delivers datasets covering load forecasts, actual generation per type and per plant, installed generation capacity, day-ahead prices, cross-border flows, scheduled exchanges, transfer capacities, balancing data, hydro storage, outage information, and congestion management data.

**Base URL:** `https://web-api.tp.entsoe.eu/api`

**Authentication:** Security token (free registration required)

**Rate Limit:** 400 requests per minute per user/IP

**Cost:** Free (EU-mandated public service under Regulation 543/2013)
